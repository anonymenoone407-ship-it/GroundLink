# GroundLink secure agent transport foundation

Phase 2B.6 provides a disabled-by-default, direct TLS transport. It is not an
HTTP/FastAPI endpoint and is not started by `server/main.py`. Uvicorn headers,
forwarded certificate headers, browser cookies, and operator bearer tokens are
never agent authentication inputs.

## Trust and certificate profile

The transport uses TLS 1.3 with `CERT_REQUIRED`. Station presents a server leaf
certificate issued by the GroundLink private CA. Agents must validate that CA,
certificate validity, and the Station DNS SAN `vm2-station`.

Station validates each client chain and validity period through OpenSSL, then
maps exactly one DNS SAN:

| Client DNS SAN | Agent ID | Role |
|---|---|---|
| `vm1-satellite` | `vm1-satellite` | `SATELLITE` |
| `vm3-channel` | `vm3-channel` | `CHANNEL` |

The subject CN is not an identity. Unknown SANs and certificates with multiple
DNS identities are rejected. `CertificatePolicy` also accepts a set of revoked
SHA-256 leaf fingerprints. Rotation is supported by issuing a replacement leaf
with the same SAN and overlapping trust, then revoking/removing the old leaf.
Production revocation data must come from an operator-controlled file or PKI
service; it must not be supplied by an agent.

## Wire protocol

Each TLS connection carries one request and one result. The request is a
four-byte unsigned network-order length followed by UTF-8 JSON. The total JSON
size is limited to 65,536 bytes. The outer object has exactly these fields:

```json
{
  "protocol_version": "1.0",
  "request_id": "unique-agent-nonce",
  "sent_at": "2026-11-01T12:00:00+00:00",
  "kind": "telemetry",
  "payload": {}
}
```

`kind` is `telemetry` or `channel_action`. Telemetry payloads are strict
`IngestedTelemetry` envelopes. Channel actions are strict `ChannelActionEvent`
objects. The response is another length-prefixed object whose status is
`accepted` or `rejected`; rejection details are intentionally not exposed.

The certificate identity is converted directly into `RequestContext.peer` on
the verified socket. JSON identity must match it. `sent_at` must be within the
configured freshness window. `(agent_id, request_id)` is atomically inserted
into Mission Control SQLite before payload persistence, preserving replay
protection across process and transport restarts.

## Deployment prerequisites

Do not enable the listener until an operator has:

1. Created a private CA and separate Station, Satellite, and Channel leaves
   outside the repository.
2. Protected private keys with dedicated OS identities and restrictive file
   permissions.
3. Established certificate issuance, expiry monitoring, rotation, and a
   trusted revocation-data update procedure. Production startup must construct
   `PersistentCertificatePolicy`; a missing or invalid policy file fails closed.
4. Selected the explicit management-interface bind address and port.
5. Added service supervision, connection/rate limits, and secret-free audit
   log collection.
6. Completed PREPARE/START run authorization and an approved LIVE activation
   transition.

No production credentials are generated by this repository. The test suite
creates an isolated ephemeral CA and leaves under a temporary directory and
deletes them after each test.
